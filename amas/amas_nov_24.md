# NOV 24 AMAS Questions and Answers

## 1. Why do we need a CSS reset?

A CSS reset removes or normalizes browsers' default styles. It helps
make the appearance of elements consistent across browsers.

## 2. Which clause is used to sort NULL values in SQL?

`ORDER BY` sorts query results, including `NULL` values. Use
`NULLS FIRST` or `NULLS LAST` (where supported) to control their
placement.

## 3. What is the difference between padding and margin?

-   **Padding:** Space between content and border (inside the element).
-   **Margin:** Space outside the border, separating elements.

## 4. What is the difference between an ordered list and an unordered list?

-   **`<ol>`:** Displays items in a numbered or ordered sequence.
-   **`<ul>`:** Displays items with bullets by default.

## 5. What is implicit and explicit type conversion?

-   **Implicit:** A type is converted automatically by the language.
-   **Explicit:** The programmer converts it manually, e.g. `int("5")`.

## 6. What is swap case?

Swap case changes uppercase letters to lowercase and lowercase letters
to uppercase. Python uses the `swapcase()` method.

## 7. What is the difference between `LEFT()` and `RIGHT()` in SQL?

-   `LEFT(string, n)` extracts the first `n` characters.
-   `RIGHT(string, n)` extracts the last `n` characters.

## 8. Which HTML tag is used to add a link to another webpage?

The `<a>` (anchor) tag creates hyperlinks. The `href` attribute
specifies the destination, e.g. `<a href="page.html">Link</a>`.

## 9. What is the `map()` function in Python?

`map()` applies a function to each item in an iterable and returns an
iterator. Example: `list(map(lambda x: x*2, [1,2,3]))`.

## 10. What is content in the CSS box model?

Content is the innermost part of an element, containing text, images, or
other material. The box model also includes padding, border, and margin.

## 11. What are common responsive screen sizes?

-   **Mobile:** below 768px
-   **Tablet:** 768px--1023px
-   **Desktop:** 1024px and above\
    These are common guidelines, not fixed rules.

## 12. What is the difference between relative and absolute positioning?

-   **Relative:** Moves from its normal position, keeping its original
    space.
-   **Absolute:** Removed from normal flow and positioned relative to
    its nearest positioned ancestor.

## 13. What are pseudo-classes in CSS?

Pseudo-classes style elements based on a state or condition. Examples
include `:hover`, `:focus`, `:active`, and `:first-child`.

## 14. What are the values of `flex-direction`?

`row`, `row-reverse`, `column`, and `column-reverse`. They control the
direction in which flex items are arranged.

## 15. What are the values of `justify-content`?

Common values are `flex-start`, `flex-end`, `center`, `space-between`,
`space-around`, and `space-evenly`. They distribute items along the flex
container's main axis.
